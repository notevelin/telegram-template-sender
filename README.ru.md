# Telegram Template Sender

[English version](README.md)

Небольшая консольная утилита на [Telethon](https://github.com/LonamiWebs/Telethon). Сохраняет шаблоны сообщений и отправляет их в выбранные чаты (личные, группы, каналы) с задержкой между кругами. Работает от твоего аккаунта Telegram, а не через токен бота.

## Возможности

- Создание и хранение шаблонов (многострочные, в `templates.json`)
- Несколько сообщений в шаблоне: отправляются по очереди
- Чаты выводятся тремя колонками (ЛС / группы / каналы), выбор по кодам вида `u0,g1,c2`
- Настраиваемые задержка и число кругов
- Лог со временем и результатом по каждому чату
- API-ключи берутся из переменных окружения, в коде их нет

## Установка

```bash
git clone https://github.com/<твой-юзер>/telegram-template-sender.git
cd telegram-template-sender
pip install -r requirements.txt
```

`api_id` и `api_hash` получи на [my.telegram.org](https://my.telegram.org) (API development tools).

## Использование

Задай ключи и запусти:

```powershell
# Windows (PowerShell)
$env:TG_API_ID="123456"; $env:TG_API_HASH="твой_api_hash"
python sender.py
```

```bash
# Linux / macOS / Termux
export TG_API_ID=123456 TG_API_HASH=твой_api_hash
python sender.py
```

При первом запуске Telethon попросит номер телефона и код входа, а сессия сохранится в `session.session`.

Дальше в программе:

1. Выбери `1` (готовый шаблон) или `2` (новый). Для нового введи число сообщений и текст каждого; каждое сообщение заканчивай строкой `STOP`.
2. Выбери чаты из таблицы, например `u0,g1,c0`.
3. Укажи задержку в секундах и число кругов.

В круге `i` отправляется сообщение `i` из шаблона; если кругов больше, чем сообщений, шаблон идёт по новой.

## Важно

- **Никогда не публикуй `*.session`.** Этот файл даёт полный доступ к твоему аккаунту Telegram. Добавь в `.gitignore`: `*.session`, `*.session-journal`, `templates.json`.
- Пользуйся ответственно. Массовые и частые рассылки могут нарушать [условия Telegram](https://telegram.org/tos) и привести к ограничениям аккаунта. Ставь разумные задержки и пиши только туда, где это уместно.
